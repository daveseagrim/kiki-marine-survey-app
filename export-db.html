Kiki Marine — Streaming DB Backup

Exports every survey and photo from KikiSurveyDB to a single downloadable JSON file. Uses IndexedDB cursors so the whole database is never held in memory at once — safe to run even with hundreds of photos.

Important: Open this page in the same browser profile where you normally use the survey app. IndexedDB is scoped per origin + profile, so a different browser or Incognito window will show an empty database.
