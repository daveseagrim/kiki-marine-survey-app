Kiki Marine — Streaming DB Backup (v2)

Exports every survey and photo from KikiSurveyDB. Uses the File System Access API to write directly to a file on your disk one record at a time, so the browser never holds the whole database in memory. Safe with any number of photos.

Desktop Chrome only. Uses showSaveFilePicker. Won't work on iOS Safari or Firefox — but that's fine, you only need to back up from the desktop browser profile where the data lives. 
Ready. Click "Just count records" first to verify you see your surveys.
