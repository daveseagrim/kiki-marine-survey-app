Import Survey Data

Import Photo Batch (JSON)

Import JPG Photos (Recommended)

Select JPG photos directly from extracted backup folders. Filenames must follow the pattern: surveyId_timestamp_hash.jpg

You can select ALL photos at once (Cmd+A). Each photo is processed individually so the browser won't crash.

Import from Local Server (Best Method)

Run the photo server in Terminal first, then click the button below. Photos are fetched and saved one at a time — no memory crashes.

python3 ~/Documents/Kiki\ Marine\ App/photo_server.py ~/Documents/Kiki\ Marine\ App/extasea-all-photos
